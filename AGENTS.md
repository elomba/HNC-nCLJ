# AGENTS.md

Guidance for coding agents (Codex, Claude Code) working in this repository.

The project has two parts: the HNC integral-equation solver for charged LJ mixtures (Fortran, `src/`), and the research studies built on it (Python analysis, LAMMPS/Slurm MD runs, LaTeX manuscripts in `doc/`). See `README.md` for theory, input cards, and output files.

## Workflow

- Claude plans, Codex implements, and Claude reviews and verifies. Codex receives a self-contained plan with absolute paths and acceptance criteria.
- Write code, comments, docs, and manuscripts in English. Converse with the user in Spanish.
- Update `CHANGELOG.md` with every relevant change, using the Keep a Changelog format and the `## [VX.Y] - YYYY-MM-DD` headings already in the file.
- Agents may submit Slurm jobs (`sbatch`, `submit.py --submit`) when the task requires it. Record job IDs in the study's submission ledger (e.g. `submissions.jsonl`, `*_submission.json`).

## Fortran solver

- The Makefile builds only `src/*.f90` into `bin/hncr_nclj`. `HNCR-nCLJ.f90` at the repo root is the historical monolithic original: keep it for reference and do not edit it.
- Build: `make` (release, gfortran `-O3 -march=native -ffast-math`). Use `make MODE=debug` (bounds checks, FPE traps) to validate any solver change.
- On this cluster, the Makefile auto-detects OpenBLAS at `/usr/local/modules/x64_v4/software/OpenBLAS/0.3.30-GCC-14.3.0`. Override it with `make LIBS=...`.
- When adding a new source file, put it in `SRCS` in dependency order and add its explicit module dependencies in the Makefile.
- The binary writes `Salida.hncr`, `Thermohncr.dat`, `RDFhncr.dat`, `skhnc.dat`, and `lsol.hncr` into the **current directory**, overwriting existing files. Run studies from their own directories.
- Regression check: `make test` runs `datosLJ.hncr` in the root. Compare `Thermohncr.dat` and `RDFhncr.dat` against `baseline_results/`. Any numerical change must be explained.
- Mole fractions: the input gives only `NSP-2` of them. The last two follow from electroneutrality. `compsi=.false.` restarts from `solin.hncr`.

## Studies and data

- `lammps_study/` is local only and excluded from git. Do not add it.
- `ComponentEntropyStudy_20261030/` and `MDPairEntropyAssessment/` are the current primary evidence. Read their `README.md` before modifying them. Preserve completed results, failed-attempt records, and provenance/checksum files, and add new outputs alongside the old ones rather than overwriting them.
- Python: `python3` from the cluster Miniconda (numpy, scipy, matplotlib, netCDF4). Validate estimator changes with `python3 MDPairEntropyAssessment/test_pair_entropy.py`.
- Lint: `~/.local/bin/ruff check <files>` (correctness rules in `ruff.toml`). New or edited Python files must pass it. Do not mass-fix existing scripts outside the task.
- MD conventions: shifted LJ cutoff 2.5σ at every density with no tail correction. The PPPM real-space cutoff is separate.

## Manuscripts (`doc/`)

- Numeric tables and `figures/component_*.pdf` are generated by `doc/generate_component_study_assets.py` (and by `MDPairEntropyAssessment/summarize.py` / `hnc_validation.py`). Edit the generators and never hand-edit generated numbers in the `.tex` tables.
- Build the PDFs with `bash doc/build_pdfs.sh [document]`. It loads the `texlive/20260310-GCC-13.2.0` module. A new document must be added to the script's allowed list.
- Keep historical benchmark values separate from the current replica data. `doc/MANUSCRIPT_DATA.md` maps every manuscript number to its source.
